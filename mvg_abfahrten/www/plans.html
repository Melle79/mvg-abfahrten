🃏 Dashboard-Karte einbinden

1 · Ressource hinzufügen (einmalig: Einstellungen → Dashboards → Ressourcen)

/local/mvg-abfahrten-card.js

Die Ressource wird automatisch registriert. Falls nötig die URL manuell eintragen.

2 · Karte hinzufügen (Benutzerdefinierte Karte → YAML-Editor)

⚠️ API-URL – Pflichtfeld

Die api_url muss in der Add-on-Konfiguration unter Einstellungen → Add-ons → MVG Abfahrten → Konfiguration als ha_ip eingetragen werden:

ha_ip: 192.168.0.222 # IP deines HA-Hosts

Danach Add-on neu starten. Die Karte erkennt die IP automatisch — auch bei Zugriff über Nabu Casa.

3 · Konfigurationsfelder im visuellen Editor

Abfahrtspläne — Pläne aus MVG → Pläne auswählen
Datenstatus-Bubble — 🟢 Live · 🟠 Veraltet · 🔴 Keine Daten
Darstellung — Tabs oder Untereinander
Uhrzeit/Minuten tauschen — Uhrzeit groß rechts
Design — Dashboard-Theme oder Abfahrtstafel
API-URL — Pflichtfeld (s.o.)
Filter-Info — Linie + Richtung unter Tabs
Reihenfolge der Pläne — Tabs per ↑↓ sortieren
Störungstext — Laufschrift bei Störungen
Anzahl Abfahrten / Aktualisierung — Limit + Intervall

📡 Alternative: Sensor-Karte (für externen Zugriff ohne API-URL)

Wenn MQTT im Add-on aktiviert ist, gibt es zusätzlich die Ressource /local/mvg-abfahrten-sensor-card.js. Sie liest sensor.mvg_abfahrten_mvg_*-Entities direkt aus Home Assistant — kein api_url nötig, funktioniert automatisch auch über Nabu Casa.
